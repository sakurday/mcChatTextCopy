# Minecraft Chat Text Copy

## 模组简介:

让玩家可以复制聊天消息为无格式文本或json格式的文本组件.

## 使用方法:

打开聊天框, 右上角有一个按钮, 点击即可打开文本复制界面.

## 模组要求

| | |
| - | - |
| Minecraft 版本 | 26.1.2 |
| Fabric Loader 版本 | >=0.19.5 |
| Fabric API 版本 | >=0.155.3 |
